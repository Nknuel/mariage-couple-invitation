# Invitation — Fatim & Zoum

Invitation de mariage en ligne (19 décembre 2026), page unique en HTML/CSS/JS.

## Contenu

- `index.html` : toute l'invitation (images, styles et scripts inclus dans un seul fichier)

## Mettre en ligne avec GitHub Pages

1. Crée un dépôt sur GitHub, puis dépose `index.html` (et ce `README.md`) à la racine.
2. Va dans **Settings > Pages**.
3. Dans **Source**, choisis **Deploy from a branch**, puis la branche `main` et le dossier `/ (root)`.
4. Enregistre. Après une minute ou deux, le site est disponible à l'adresse :
   `https://<ton-pseudo>.github.io/<nom-du-depot>/`

## Remarques

- Les polices (Fraunces, Alex Brush) sont chargées depuis Google Fonts : une connexion internet est nécessaire pour les afficher.
- Le fichier pèse environ 5,7 Mo, ce qui reste sous la limite de 25 Mo de l'envoi par navigateur sur GitHub.
